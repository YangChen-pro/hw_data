### 步骤2 如果AP被误加入黑名单

1. 请执行命令`display ap blacklist`，查看被加入黑名单的AP的MAC地址。

```bash
<WAC> display ap blacklist
Total: 1
--------------------------------------------------------------------------------
ID    MAC
--------------------------------------------------------------------------------
0     00e0-fc07-8280
--------------------------------------------------------------------------------
```

2. 执行命令`undo ap blacklist mac ap-mac`，删除AP黑名单中的指定AP。

```bash
<WAC> system-view
[WAC] wlan
[WAC-wlan] undo ap blacklist mac 00e0-fc07-8280
```
